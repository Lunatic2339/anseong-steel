# v04 손목 기준 자세·회전 검수

기존 v03 결과물은 보존했습니다. 이번에는 손의 기준 방향과 전완·손목의 회전 배분을 수정했습니다. 실제 컨트롤러 입력, 물체 잡기 로직, 통신, 새 애니메이션은 추가하지 않았습니다.

## 변경 내용

- 기본 검수 자세에서 손가락의 길이 방향을 전완 방향에 맞춰 손목이 꺾인 자세를 기준으로 삼지 않도록 했습니다.
- 머리 위로 들기, 가드, 앞으로 뻗기에서도 손등 방향을 각각 정렬했습니다.
- 비트는 회전은 전완 시작 부분에 35%, 전완 끝 외장에 총 90%, 손에 100%가 적용됩니다. 따라서 손목 경계에 남는 축 방향 비틀림은 10%입니다.
- 손목의 청록색 띠를 전완 끝 외장과 같은 보조 본에 연결했습니다.
- Unity 검수 리그의 기본 제한은 앞뒤 굽힘 ±35도, 좌우 꺾임 ±20도, 전완 비틀림 ±100도입니다. 이는 이 모델을 위한 조절 가능한 제작 기준이며 인체의 보편적인 가동 범위라는 뜻은 아닙니다.
- 제한을 넘으면 목표 손의 방향을 그대로 따라가지 않고 제한된 자세를 유지합니다. 화면에 각도 제한 안내가 표시됩니다. 팔 길이를 넘는 위치도 기존처럼 늘리지 않고 멈춥니다.
- 각 손에 `GripReference_Left` / `GripReference_Right`를 추가했습니다. 나중에 컨트롤러·조종간을 맞출 때 사용할 손바닥 기준점입니다.

Play를 누르고 Game 창을 클릭합니다. 기본 화면 오른쪽 상세 모델을 조작하며 왼쪽은 감량 모델입니다.

- **Aligned hands / open**: 손목을 정렬하고 손 펴기.
- **Aligned hands / close**: 같은 손목 방향에서 손가락 쥐기.
- **Roll -60 / +60**: 정렬된 손목을 유지하면서 전완 비틀기.
- 좌우 Grip 슬라이더: 각각의 손가락 쥐기 정도.
- 1: 머리 방향, 2/3: 왼손/오른손, 4/5: 팔꿈치 조절점 선택.
- WASD와 Q/E: 손·팔꿈치 조절점 이동. 방향키와 Z/C: 머리·손 회전.
- Tab: 정지 검수 자세 전환, R: 기본 자세, G: 양손 펴기/쥐기.
- 마우스 오른쪽 드래그: 카메라 회전, 휠: 확대/축소, F1: 안내 표시.

## 나중에 컨트롤러를 연결할 때

손 타깃의 **+Z는 편 손가락 방향, +Y는 손등 방향**입니다. 타깃의 위치는 손목 위치입니다. 컨트롤러 좌표를 그대로 복사하는 대신, 실제 쥔 방향에 맞춘 위치·회전 보정값을 거쳐 이 타깃으로 전달합니다.

손바닥 기준점은 손목에서 손가락 쪽 4.5cm, 손바닥 쪽 2cm인 초기값입니다. 실제 컨트롤러나 손잡이에 맞춰 조정해야 합니다. 조종간을 잡을 때는 조종간의 잡는 기준점과 이 손바닥 기준점이 일치하도록 손목 타깃을 계산합니다. 쥐는 손가락 자세도 손잡이 굵기에 맞춰 별도로 조정합니다. 이 버전은 그 기준점까지 준비했으며 붙잡기/놓기 기능을 구현한 것은 아닙니다.

현재 다리·골반은 고정이고 머리는 방향만 제어합니다. 실제 Quest 착용, 컨트롤러 오프셋, 조종간 접촉, 기기 성능은 미검증입니다. 모든 극단적인 자세의 외장 관통 방지를 보장하지는 않습니다.

## 파일

상세·감량 모델 양손 모두 Unity 검사와 재생 모드 조작 검사를 통과했습니다. 순수 72도 비틀기에서 전완 시작 25.2도, 전완 끝 64.8도, 손 72도를 확인했고 손의 길이 방향과 전완 축의 각도 오차는 0도였습니다. 각도 제한을 넘는 입력과 180도 경계 통과 시 갑작스러운 반전 여부도 검사했습니다. 이는 검사한 자세와 수치에 대한 결과이며 실제 착용감까지 검증했다는 뜻은 아닙니다.

- `AS_Pilot_v04.blend`: 손목 띠 가중치와 전완 보조 본을 수정한 Blender 원본. 기존 정지 검수 자세는 유지했습니다.
- `AS_Pilot_v04.fbx`: 상세 모델, 86,032삼각형.
- `AS_Pilot_v04_QuestCandidate.fbx`: 감량 후보, 39,572삼각형.
- `PilotV04_Review.unitypackage`: 새 Unity 씬, 재질, 리그, 조작 기능.
- `UnityValidation/`: Unity 자세 렌더 및 검사 결과.

Blender의 기존 제약 리그와 Unity의 회전 제한 리그는 구현 방식이 다릅니다. 손목 정렬·각도 제한의 최종 확인 기준은 새 Unity 검수 씬입니다. 메시에는 기존 58본을 유지했습니다. 기존 Desktop 콕핏 작업 공간은 변경하지 않았고 커밋·푸시도 하지 않았습니다.
