# 1인 양팔 더미 연습 모드

메인에 코드와 설정을 반영했다. 사용자 지시에 따라 Unity 실행, 컴파일 검사,
Play, 배치 검사와 HMD 검증은 수행하지 않았다. 아래는 구현된 진입 경로와
조작법이며 실제 실행 성공을 확인한 보고가 아니다.

## 시작과 복귀

기존 `AnseongSteel/Assets/_Project/04_Scenes/sunwoo_IntegratedPlay.unity`를 사용한다.
`Robot Combat Authority` 세션에만 실행 시 연습 모드가 붙는다. 기존 씬 파일은
수정하거나 다시 생성하지 않았다. 다른 팀원 씬, VR_test, ArmMotionTest 및
검사용 임시 씬에는 이 기본 모드를 붙이지 않는다.

`Assets/_Project/RobotPlay/Runtime/Resources/SoloPracticeSettings.asset`의
`startInPractice`가 기본 true다. false로 바꾸면 기존 모드로 시작한다.
실행 중 F9는 연습/기존 모드 전환이다. 모드 전환과 리셋 후에는 다시 보정한다.
실제 LAN 연결 중에는 전환을 거절하며 타 사용자의 연결을 강제로 끊지 않는다.

1. 머리와 양손이 추적되는 상태에서 편한 가드로 Y를 눌러 양팔 가드를 저장한다.
2. 왼팔을 편하게 뻗은 위치에서 X, 오른팔에서 A를 눌러 도달점을 저장한다.
3. 그립을 놓고 가드로 돌아온다. 가드에서 잠시 머무른 후 새 타격을 받는다.
4. 기본 자유공간에서 그립을 누르고 잽/훅/손목 정렬을 비교한다.
5. 오른 스틱을 위로 밀었다 놓거나 F10을 눌러 자유공간 → 잽 거리 → 가까운 훅
   거리 → 자유공간으로 전환한다. 훅 거리는 초기 튜닝값이며 실제 적정 거리는 미검증이다.
   기둥은 보정한 도달 방향과 새 리그 판정 범위를 사용해 놓는다. 가까운 실제
   접촉에서는 팔이 굽은 채 멈출 수 있다. 접촉을 무시하고 강제로 펴지 않는다.
6. 그립을 유지한 실제 주먹 접촉은 좌우 명중 수, 색 변화, 짧은 진동으로 알린다.
   가드로 복귀하기 전에는 같은 접촉을 반복 명중으로 세지 않는다.

| 입력 | 기능 |
|---|---|
| Y / X / A | 가드 / 왼팔 도달 / 오른팔 도달 저장 |
| 좌우 그립 유지 | 해당 팔 공격 의도 |
| B 또는 R | 연습 리셋·재보정·자유공간으로 복귀 |
| 오른 스틱 위 또는 F10 | 자유공간/잽/근거리 훅 순환; 아바타 이동 기능은 아님 |
| F9 | 기존 콕핏/보스 모드 복귀 또는 연습 진입 |
| F11 또는 PC 왼쪽 위 버튼 | PC 1인칭 미러/3인칭 관찰 전환 |
| F1 | XR/키보드 입력 전환 |
| F/G + 1/2/3/4 | 키보드 공격 유지 + 좌/우 잽/훅, 임시 디버그 입력 |

PC 3인칭은 같은 실제 팔 뼈와 전신을 고정된 3/4 시점에서 본다. 선택할 때만
관찰 카메라와 RT를 만들고, 해제/모드 종료 시 없앤다. HMD 카메라를 바꾸지
않으며 자동 orbit나 머리 추종 지연을 넣지 않았다. 명시적 거리 전환 시에만
관찰 프레임을 다시 구성한다. HMD에서의 PC UI 표시/양안 렌더링은 미검증이다.

## 플레이어와 입력 구성

현재 씬의 확인된 보스 Animator 시각 루트를 비활성 상태에서 복제한다.
복제 인스턴스의 NPC 스크립트/Animator/기존 콜라이더/소리·효과를 중지·제외하고,
다음 프레임에 활성화한다. 원본 보스, FBX, CompatibleSkins, 재질과 클립은
변경하지 않는다. 새 팔 뼈가 실제 표시와 충돌 모두를 구동하므로 v026 시각 팔의
캐시가 새 리그를 덮지 않는다. 종료 시 기존 참조와 렌더링/입력/카메라 설정을 복구한다.

아트의 58-bone 매핑을 사용한다. 좌우 각각 상완/전완/손, 세 query Box,
손가락 15개를 연결한다. 첫 사람의 왼손/오른손이 각각 좌우 팔을 제어한다.
미래 원격 입력의 경계는 기존 per-arm Submit에 남지만 원격 리치/회전 동기화가
완성됐다는 뜻은 아니다. 협동/RPC 코드를 삭제하거나 전역으로 비활성화하지 않았다.

원본 공격 클립의 일정한 손가락 Quaternion 20개와 bind joint3 10개를 재사용한다.
이는 초기 주먹 자세 후보이며 실제 닫힘은 미검증이다. v026 Configure의 손가락
각도나 v026의 팔 길이·주먹 크기는 재사용하지 않았다. 보조 Idle/하체 Mixamo
애니메이션의 Generic 재사용 경로는 아트 자료로 남았으며 아직 적용하지 않았다.

로컬 HMD에서는 아트의 팔 Renderer 142개를 표시하고 몸/머리 149개를 가린다.
3인칭에는 전신을 표시한다. 카메라별 가림이며 원본 몸체를 삭제하지 않는다.
연습용 복제와 기둥에만 layer26을 사용한다. 원래 모델 layer는 바꾸지 않는다.
중계와 feed 카메라를 중지하고 기존 HMD 카메라/입력 소유자를 재사용한다.

## 초기 튜닝과 미검증 항목

시야는 새 모델 Head 위치 + root 기준 offset `(0,.04,.12)`의 초기값이다.
가드는 실제 segment 길이의 .48 비율과 초기 방향으로 만든 고정 앵커다.
검증된 인체 앵커가 아니며 Settings의 viewOffset/guardReachFraction으로 조절한다.
개인 도달점은 약 3도 굽힘, overreach는 약 2도의 양의 여유를 유지한다.

로봇 팔만 길이 × `armReachPerSecond=1.2` 제한속도와
`armResponseSeconds=.14`의 반응 완화로 따라온다. HMD, 입력 판독, 보정 프레임을
늦추거나 동작을 큐에 쌓지 않는다. 표시와 접촉은 같은 구동 목표를 따른다.
그립 해제/추적 손실/리셋은 공격 의도와 목표 속도 상태를 지운다.

연습 명중은 최소 이동 속도 대신 그립, 유효 전방/곡선 경로, 실제 주먹 접촉,
가드 복귀를 조합한다. 매우 느린 유효 동작도 배제하지 않는 구성이며, 천천히
팔을 올리는 동작이나 추적 손실을 자동 공격으로 만들지 않는다. 감각·인식 정확도는
실기에서 확인하지 않았다. 포스피드백 장치 제어나 하드웨어 프로토콜은 추가하지 않았다.

정적 확인: 설정/script/profile GUID, 정확한 씬 마커, 매핑의 표시/숨김 분리,
각 손 15개 Quaternion/세 판정 Box, 파일 차이/복구 경로를 검토했다.
보호 파일 17개와 기존 씬 해시는 유지됐다. 49개 보스 collider 프로토타입은 반영하지 않았다.
컴파일, 실제 진입/복귀, 눈 높이/크기감, 손가락 닫힘, 느린 경로 판정, 충돌 관통,
양안/HMD/PC 관찰, 성능은 모두 실행 미검증이다.
