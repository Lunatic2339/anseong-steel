사용자 요청
이미지와 프로젝트 모델을 하나씩 직접 확인하고 구동·검증할 것. 모델은 모델 자체와 리깅 상태까지 확인할 것.
기존 01~04 보고서는 정적 진단 및 대화 검토를 중심으로 했으며, 이 요청의 완료 기준을 충족하지 않았다. 05의 검토 한계는 계속 유효하다.

검증 완료 기준
1. 각 대상의 정확한 경로·버전·기준 커밋·사용 씬을 기록한다. 같은 이름의 원본/내보내기/Unity 임포트 결과를 구분한다.
2. 항목별 상태는 실행 확인 / 육안 확인 / 정적 확인만 / 실패 / 미검증 / 해당 없음으로 구분한다. 모든 파일에 모든 검사를 적용하지 않고 해당 없는 이유를 쓴다.
3. 모델은 메시·재질·축·스케일·본 계층·스킨웨이트·바인드포즈·누락 참조, 포즈별 변형·관절 간섭을 검사한다. 로봇 rigid 부품과 인체 skinned mesh에 맞는 검사를 사용한다.
4. Unity 저장 씬을 직접 열고 PlayMode 또는 실행 빌드에서 실제 연결을 확인한다. 자동 재생성/복구 후에만 통과한 씬은 원본 통과로 쓰지 않는다.
5. 합성 입력/내부 직접 호출/실제 플레이 입력/실기기 입력의 결과를 구분한다. 테스트 코드 PASS와 게임에서 기능 도달 가능 여부를 구분한다.
6. 각 결과에는 기대 동작·실제 결과·재현 방법·로그·캡처·우선순위를 남긴다. 자료만 존재하거나 오래된 캡처만 있는 항목은 신규 실행 완료로 쓰지 않는다.
7. Quest 양안 시야, 실제 두 PC/두 Quest, 신체 크기별 교정, 멀미·장시간 성능, 외골격은 환경이 있을 때 실검증한다. 데스크톱/동일 PC 다중 프로세스 결과로 대체 통과하지 않는다.
8. 대상별 목록을 보고 누락 여부를 확인한다. 실패나 환경 제한으로 못한 항목은 목록에서 없애지 않는다.

UI·빌드·성능·시연 운영: 최신/과거 HUD 시안과 적용 이미지 직접 보기, 좌우/정상/공격/피해/가드/콤보·부스트/대기/설정 상태 실제 렌더 및 조작. 07_HUD_VISUAL_RUNTIME_VERIFICATION.txt 예정.
